# HelidoDownloaderFalconi
Distribución oficial de **Falconi**, la app para hablar con tu agente (Samy / Falconi) desde el celular: APKs firmados.

Los APKs se publican como `Falconi-<versión>.apk` en las releases. Paquete `com.h3l1d0.falconi`; cada versión se instala encima de la anterior (misma firma). La app se actualiza sola desde `api.trademer.com/falconi/update-manifest`.
